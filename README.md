# Two Worlds — 0.1 P2P

Статическая браузерная игра. Загрузите index.html и game.js в корень публичного репозитория GitHub, затем Settings → Pages → Deploy from a branch → main / root → Save. Откройте опубликованную HTTPS-ссылку на обоих телефонах.

1. Первый игрок нажимает «Создать приглашение», копирует исходящий код и отправляет второму.
2. Второй вставляет код, нажимает «Ответить на приглашение», копирует ответ и отправляет первому.
3. Первый вставляет ответ и нажимает «Завершить подключение».
4. Держите обе вкладки открытыми. Синий активирует синюю плиту, оранжевый — оранжевую; мосты остаются открытыми. Оба идут к порталу.

Управление: джойстик и прыжок, клавиатура WASD/пробел, совместимый геймпад. Лучше горизонтальная ориентация.

Требуется интернет для загрузки Three.js с CDN и STUN. TURN не настроен: некоторые мобильные сети не позволят установить прямое соединение. Коды длинные, содержат сетевые сведения, отправляйте только друг другу. При разрыве создайте новое приглашение. Не протестировано на физических телефонах.
